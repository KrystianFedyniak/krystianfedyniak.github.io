## О проекте

Персональный сайт-портфолио, полностью написанный на чистом HTML, CSS и JavaScript — без фреймворков и зависимостей. Демонстрирует опыт, проекты, стек технологий, сертификаты и контактную информацию.

Сайт оптимизирован под SEO, адаптирован под все устройства и доступен в Google Search.
